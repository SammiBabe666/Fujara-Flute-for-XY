# Changelog

## 0.1.0 (unreleased): first release candidate

- Fujara (`fujara`), a four-control overtone-flute synth for Open-XY (SDK 1.6, OS 1.2.1):
  Breath, Body, Overtones, Air.
- Six presets: Mountain Breath (default), Overtone Wraith, Mourning Wood, High Pasture,
  Storm Calling, The Hollow Saint.
- Monochrome engraved screen with breath wisp, overtone ladder and window glow.
- Host tests, release checks, CI with sanitizers and a native Blackfin compile.
- Hero artwork, device screenshot, thumbnail, and a 2:47 demo and preset tour.
- Pending: device build, audition and hardware CPU readout.
